## 近期方向

- **科学计算 Agent**：把任务规划与确定性执行、结果解析和验证分开，让计算过程可追踪、可恢复。
- **模型评测工具**：将测试数据整理、指标计算、复核与报告流程做成可重复使用的工具。
- **材料生成与筛选**：评估生成结构的有效性、多样性和新颖性，并探索 DFT 前筛流程。

## 精选项目

| 项目 | 简介 | 技术 |
| --- | --- | --- |
| **[DFT-Forge](https://github.com/liyu230405/dftforge)** | 面向科学计算的通用 Agent 工具链，支持 Quantum ESPRESSO、VASP 与 ABINIT；由确定性程序负责输入生成、执行、结果解析和验证，并记录运行证据。 | Python · FastAPI · SQLite · DFT |
| **[模型评测 Skills](https://github.com/liyu230405/model-evaluation-skills)** | 收录 VLA 对比报告生成与基模测试质检初筛工具，强调指标复核、规则透明和人工最终判定。 | JavaScript · Python |
| **[CDVAE Crystal Screening](https://github.com/liyu230405/cdvae-crystal-screening)** | 面向 Perov-5、Carbon-24 与 MP-20 的晶体生成评测和 DFT 前筛流程，覆盖结构质量、有效性、多样性与代理指标。 | Python · PyTorch · pymatgen · CHGNet |
| **[WaveMind](https://github.com/liyu230405/wavemind-electronics-emi)** | 面向民用电子设备 EMI 研究的材料工作台，提供公开材料记录、工程约束筛选和边界明确的模型探索。 | JavaScript · CSS |
| **[拼豆图纸工坊](https://github.com/liyu230405/pingdou-pattern-studio)** | 在浏览器本地把图片转换为带网格、色号和用量清单的拼豆图纸，可导出高清 PNG。 | TypeScript · React · Canvas |
| **[MiniTag](https://github.com/liyu230405/minitag)** | DIY BLE 寻物器，包含 SwiftUI iOS App 与 XIAO nRF52840 固件。 | SwiftUI · CoreBluetooth · BLE |
